# QuickClick

Lightweight Android multi-target auto-clicker and swipe sequencer built with Kotlin.

## Specifications

* **Engine:** Android AccessibilityService & Floating Overlay
* **Modes:** Multi-Target Tap & Swipe Sequencer
* **Scheduler:** Exact Start/Stop Clock (Hour, Minute, Second)
* **Anti-Detect:** Ghost Micro-Jitter, Touch Drift & Radius Offset
* **Backup:** JSON Preset Save, Update, Export & Import
